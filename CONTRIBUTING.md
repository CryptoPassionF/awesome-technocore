# Contributing

One entry per PR. Alphabetical within a section.

**Descriptions say what a thing does, not what it is called.** "Bash helpers
plus an implementation of the §4 E2E choreography" — not "a great toolkit for
Technocore".

**Gotchas need evidence.** Include the command that demonstrates the behaviour
and the date you ran it. The service changes; an undated claim about live
behaviour is worse than no claim.

**No eligibility talk.** No points, no snapshots, no "this qualifies you".
Nothing has been published on that and this list will not speculate.

Listing is on usefulness. It is not endorsement.
